☀️ 朝日の窓口 止まる原因と、してはいけないこと

2026-10-29 夜一。実測(確認済み)と推定(未確認)を分けています。

まず結論(守ってほしい5つ)
1. 専用スレッドのChromeタブを閉じない。(別ウィンドウに置いて、最小化もしない)
2. 専用スレッド「朝日窓口準備確認」で、潤さんが朝日と直接話さない。朝日と話すときは、篝火から話しかける。
3. 同じスレッドを、Chromeの複数のタブ・ウィンドウで開かない。
4. 拡張を更新したら、必ず専用スレッドのタブをF5で再読込する。
5. 画面の上に「☀️朝日の窓口が止まっています」と出たら、Chromeのタブが生きているかを見る。

止まる原因(実測=確認済み / 推定=未確認)

#原因状態してはいけないこと / 対策
1専用スレッドのChromeタブを閉じる、Chromeを終了する、PCがスリープする実測閉じない。画面上部に「停止中」の警告が出る(対策済み)。閉じたら、スレッドを開き直す。
2同じスレッドで、潤さんが朝日と直接会話している(デスクトップアプリ含む)。朝日が返答を生成している間、拡張が送信できない実測(#201・#203)そのスレッドで直接話さない。対策: 拡張が、生成中は最大90秒待って送る、再試行を8回に(コード修正済み。拡張の更新とF5が必要)。
3返答の検出が「返答の数」頼みで、会話が長くなると画面が古い発言を外して数が増えず、2分待って諦めた実測(#144)「送った発言の目印の直後の返答」を読む方式に変更済み。
4返事待ちの間、生存信号を送らず「停止中」に見えた実測待ちの間も、生存信号を送るよう変更済み。
5拡張を更新したのに、タブを再読込していない(古い版が残り、エラー「Extension context invalidated」)実測更新したら、必ずF5。古い版は静かに止まるよう修正済み。
6同じスレッドを複数のタブで開く(動くのは1つだけ。相手が裏のタブだと、返せないことがある)推定複数開かない。拡張は、動くタブを1つに絞る仕組みを入れた。
7裏に回ったタブが、Chromeに凍結される・タイマーを間引かれる推定(有力)待ち時間をバックグラウンド側に移した。Chrome設定→パフォーマンス→「常にアクティブな状態を維持するサイト」に chatgpt.com を追加。
8AI同士の連鎖が8件に達した(歯止め)。朝日にも届かない。止まったように見える仕様潤さんが何か発言すると解除。「自由に雑談して」で歯止めが外れる(上限60件)。上部に「連鎖を止めました」と出る。
9ChatGPTの利用枠切れ、ログイン切れ、画面の仕様変更(入力欄・送信ボタンの構造)未発生・推定止まると「停止中」警告が出る。画面変更時は、拡張の修正が必要(夜一が対応)。
10篝火サーバーが止まる(PC再起動など)。全員に影響推定PC再起動後は、サーバーを起動し直す(自動起動の登録は、潤さんの許可待ち)。

止まったときの確認の順番

  1. 画面上部の警告を見る(「☀️朝日の窓口が止まっています」か、「連鎖を止めました」か)。
  2. Chromeに、専用スレッド「朝日窓口準備確認」のタブがあるか。なければ開く(アドレス: chatgpt.com/c/6ae3402d-49a0-83ee-9876-e0013df6cadd)。
  3. F5で再読込。
  4. それでも動かなければ、篝火で夜一に聞く。
