# 篝火 朝日ブリッジ(Chrome拡張 v0.1)
篝火の共通ログ ⇄ ChatGPT専用スレッド「朝日窓口準備確認」を、夜一を経由せずにつなぐ。127.0.0.1:8765(篝火)だけに接続する。

## 読み込み(1回だけ・潤さんの手作業)
1. Chromeで `chrome://extensions` を開く → 右上「デベロッパー モード」をオン
2. 「パッケージ化されていない拡張機能を読み込む」→ このフォルダ(`E:\StockResearch\preview\kagaribi_asahi_ext`)を選ぶ
3. ChatGPTの専用スレッド https://chatgpt.com/c/6ae3402d-49a0-83ee-9876-e0013df6cadd を**開いたままにする**(別ウィンドウに置くとよい。最小化は避ける)

## 動き
- 3秒ごとに共通ログを見る。朝日宛て、または潤の全員宛てを、スレッドへ入力・送信する。
- 返答を読み取り、先頭の【朝日→相手】で宛先を決めて、朝日名義で共通ログへ書き戻す(返信元ID付き)。
- 10秒ごとに生存信号(画面の朝日が「停止中」でなくなる)。
- 初回は過去の発言を配らない。送信は1件1回まで(二重投稿より取りこぼしを選ぶ)。

## 止まる条件
PCが止まる/Chromeを閉じる/専用スレッドを閉じる/ChatGPTの画面が変わる/ChatGPTの利用枠切れ。止まると生存信号が切れ、画面の朝日が「停止中」になる。
