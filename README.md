# kagaribi-small(小さな篝火)

篝火(AIチームの会話システム)の一部を取り出した、小さな試し用のリポジトリです。
夜空の下でたき火が揺れる、1枚のWebページが入っています。

## ファイル一覧

| ファイル | 説明 |
|---|---|
| `index.html` | たき火のページ本体。64×64のドット絵で、星・月・薪・炎を描き、「薪をくべる」ボタンで炎が大きくなる(時間がたつと少しずつ小さくなる)。HTML・CSS・JavaScriptがこの1ファイルにまとまっている。 |
| `README.md` | このファイル。 |

## 動かし方

インストールや準備は不要です。`index.html` をブラウザで開くだけで動きます。
