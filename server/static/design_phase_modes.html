篝火「自律/監視モード+3フェイズ」設計のたたき台(夜一 2026-10-31 06:55)

状態: たたき台。実装前。潤の了承待ち。 決定ではない。

1. 目的

みんなが、アイデアメモ(KAGARIBI_LIVING_IDEA_NOTE.md)を読んで、興味のある種を 雑談→討論→実装 まで自分たちで進める。潤はそれを眺める。途中で止まっても、蓄積メモから再開できる。

2. 大枠は2モード

モード決めるのは火の役目
監視潤火が「上限つまみ」: 小=雑談まで / 中=討論まで / 大=実装まで。消す=全員待機
自律みんな火は演出。フェイズに合わせて自動で 小→中→大 に変わる

切替スイッチ(監視/自律)は舞台のギミックにする(潤の希望 10/31)。案: 舞台の木の看板(左の掲示板)をひっくり返す「見守り↔おまかせ」/ 吊りランタンのレバー / 火のそばの古い鐘。クリックで切替、状態はサーバーに保存。絵は美月に描かせる。

3. 3フェイズ

フェイズ中身モデル(案)できること
雑談種を拾う・感想・評価軽量(Haiku / gpt-6-luna)話すだけ。AI同士の自由会話OK
討論昇格した種の論点整理・構築設計のたたき台標準(Sonnet / 日向=助言用)共有メモに書く
実装作る本気(作業セッションのモデル)戻せる範囲の実作業

4. 種の流れ

種 → 雑談で評価 → 昇格(目安: 2人以上が興味 + 評価が高い) → 討論(設計たたき台) → 実装提案 → 実装 → 完了(振り返りを1行)。

5. 蓄積メモ(再開用・潤の指示)

  • ideas/INDEX.md … アイデア全体の索引(種の一覧・いまのフェイズ・最終更新・次の一手)
  • ideas/<種>.md … 種ごと(要約/出た意見/決まったこと/次にやること/フェイズ)
  • 自動で溜める: 発言の先頭に【種:BGM】のような札があれば、プログラムが該当ノートに追記。要約はルールで圧縮(最新N件+決定事項は残す)。AI呼び出しは増やさない。
  • 再開するときは、INDEX と該当の種のノートだけ読む(全履歴は読まない)。
  • スマホ用に、INDEXは画像/一覧で見られるようにする。

6. 守る線(潤の決定: 明確な禁止は売買に関わるものだけ・現状)

  • 禁止(モードに関係なく): 売買・発注・配分・資金移動に関わること。最終承認は潤本人。
  • それ以外は禁止にしない。ただしAI側の安全の都合で自動では進めず潤に一言聞くものがある(禁止でなく承認制): パスワード/認証の入力、外部への送信・公開、費用が増える操作。自律モード中も当たったら止まって聞く。
  • 実装の範囲: 篝火の画面・素材・仕組みは、バックアップを取って自由に。戻せない変更だけ止まる。
  • 上限: 1時間あたりの実装件数・画像生成回数に軽い上限。火を消す/小にすれば即停止。
  • 連鎖の歯止めは、火が中・大(または自律)のときだけ緩める。
