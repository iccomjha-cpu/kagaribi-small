1. 声(Gemini TTS)を画面で作る【美月】

  • 場所: https://aistudio.google.com/generate-speech 〔実測〕。Chrome(ユーザーのログイン済み)で開く。画面の利用は、APIキーを選ばなければ無料。
  • 注意: 無料枠の入力は Google の製品改善に使われる。機密・個人情報・子供が写る素材の情報は入れない。台詞だけなので問題なし。
  • 手順〔実測〕:
  • 「Create new dialog」(掛け合い)で、台詞を入れる。話者は 1 回に 2 人まで。
  • Style(演技指示)に、年齢・感情・語尾を書く(下の例)。
  • 右の Speaker settings で声を検索して選ぶ(例: Zephyr / Leda / Sola / Fola / Laomedeia / Elio)。
  • Run。Cookie の案内が Run を隠したら「同意しない」を選ぶ。
  • 下のダウンロードで WAV を保存。保存すると画面が最初に戻るので、1 声ごとに作り直す。
  • 演技指示のコツ〔実測〕:
  • 年齢は数字で書く(「約4歳」)。「小さく・とても高く・甘く・ゆっくり・舌足らず」が効いた。
  • 語尾は「自然に下がり、上がらず、伸ばさない」と書くと安定した。
  • 例(ルネ・約6歳・驚き): 約6歳の元気な女の子、驚き。自然な日本語のアクセント。短く軽く。語尾は自然に下がり、上がらず、伸ばさない。
  • 例(コハク・約7歳): 約7歳の元気な男の子、あわてて心配。語尾は自然に下がる。
  • 笑い・間は <laugh> <short pause> などのタグ(英語のタグ推奨)。台詞は逐語の台本として読まれる。
  • 決まった声〔実測・本人評価〕: ルネ=パターンG(Zephyr+「幼く」の指示+後処理でピッチ+8%)。コハクは Elio(中くらい)+「約7歳の男の子」で代用。男の子の高めの声は無料の範囲で見つからず。
  • 保存先の約束: ダウンロード先に落ちた最新の WAV を、依頼で指定された場所へコピーして名前を付ける(元は消さない)。

2. 曲・ジングルを Lyria で作る【美月が担当・画面で試す→無理なら夜一がAPIで作って渡す】

  • 美月: AI Studio の画面(https://aistudio.google.com/)に音楽生成(Lyria)があるか確認し、あれば §1 と同じ要領で、下のプロンプトの型(英語・歌なし・時間ごとの流れ)を入れて保存する。画面に無い/作れないときは、その旨を結果に書いて夜一へ依頼する(未確認のことを、できたと書かない)。
  • 夜一(API の方法・実測 10/19):
  • 鍵: E:\YUMEMORI\_keys\gemini_api_key.txt(中身は読み上げない・ログや会話に出さない)。課金は従量で、本人の承認した少額の範囲(1 曲 約0.08ドル、30秒クリップ 約0.04ドル)。
  • 呼び方〔実測 10/19〕(Python・標準ライブラリのみ。python -I で実行):
import json, urllib.request, base64
k = open(r'E:\YUMEMORI\_keys\gemini_api_key.txt', encoding='utf-8-sig').read().strip()
prompt = "Instrumental only, no vocals. ... (英語。楽器・テンポ・[0:00 - 0:05] のように時間ごとの流れを書く)"
body = {"model": "lyria-3-clip-preview", "input": prompt, "response_format": {"type": "audio"}}
req = urllib.request.Request('https://generativelanguage.googleapis.com/v1beta/interactions',
      data=json.dumps(body).encode(), headers={'x-goog-api-key': k, 'Content-Type': 'application/json'})
r = json.load(urllib.request.urlopen(req, timeout=300))
for s in r.get('steps', []):
    if s.get('type') == 'model_output':
        for c in s.get('content', []):
            if c.get('type') == 'audio':
                open(r'出力先.mp3', 'wb').write(base64.b64decode(c['data']))
  • コツ〔実測〕: 歌なし(Instrumental only, no vocals)を先頭に。長さの指定は無視され、約25〜30秒で出る。時間ごとの流れ [0:00 - 0:05] は効く。やさしい曲は、鈴・オルゴール・ハープ・ピチカートなど。
  • 採用ジングルの作り方は、E:\YUMEMORI\04_音\ジングル\★採用_ジングル案1_作り方.md(ffmpeg のフィルター値つき)。

3. 後処理(ffmpeg)【夜一】

  • ffmpeg は imageio_ffmpeg.get_ffmpeg_exe() を使う(別に入れなくてよい)〔実測〕。
  • AI Studio の WAV はヘッダーが不正なので、必ず作り直してから切り出す〔実測〕: ffmpeg -y -i 元.wav -ac 1 -ar 24000 -c:a pcm_s16le 元_clean.wav
  • 台詞ごとの切り出しは、無音を検出して区切る(会話記録の一時スクリプト seg.py。保存されていないため、必要なら作り直す)。
  • ピッチ +8%: 動画づくりの一時スクリプト(mixvoice2.py)で実施。方法は保存されていない〔未確認〕。作り直すなら asetrate=24000*1.08,aresample=24000 等。
